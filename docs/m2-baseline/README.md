# M2 定型快照 —— M3 的对照物

迁移计划 M2.5-pre 的产出。**M3 的验收标准是「界面长得和 M2 的截图一模一样」**，
所以这里存的是那几张截图，以及生成它们的那一页。

| 文件 | 内容 |
| --- | --- |
| `index.html` | 快照页。引用 `frozen/` 下的冻结副本 |
| `frozen/app.css`、`frozen/present.js` | M3 删掉 `public/` 之前的最后状态，**不要再改** |
| `01-word-marks-8-combos.jpg` | 逐词三层标记，三个维度的 8 种组合＋漏读/多读/单值枚举三种边角 |
| `02-phoneme-popover.png` | 音素弹出层（悬停「三样都占」的那个词） |
| `03-pitch-and-scores.png` | 音高曲线、分数分档、文案与元信息 |

## 怎么重新生成

```bash
cd <repo root>
python3 -m http.server 5200 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:5200/docs/m2-baseline/index.html
```

## 三条关于这份快照本身的纪律

**一、它原本引用本体，不复制本体；M3 之后改为冻结。**
`public/` 存在的时候，页面 `<link>` 的是 `../../public/app.css`，`import` 的是
`../../public/present.js`——复制一份进存档，它和本体**一天就会分叉**，
而分叉之后这张「对照物」会安静地开始撒谎。

M3.9 把 `public/` 整个删了（决定逻辑搬进 `src/renderer/lib/present.ts`），
判断因此反转：**没有本体可以分叉了，而存档必须还打得开**。
所以 `frozen/` 下是那一刻的冻结副本，不再跟随任何东西变化。

**二、数据是写死的 fixture，这是刻意的。** 截图必须可复现，
而一次真实录音不可复现。fixture 覆盖的是三个维度的全部 8 种组合，
比任何一次真实评分都更完整。

**三、它不是应用本身。** M2 那一刻的应用入口是 `public/index.html`（已随 M3.9 删除），
现在的入口是 Electron 的渲染层 `src/renderer/`。
这一页只渲染结果区，没有录音、没有合成、不发任何请求。
M3 对照时看的是**结果区长什么样**，不是「这一页能不能跑」。

## 快照里的三层，各对应哪个字段

| 层 | 视觉 | 字段 |
| --- | --- | --- |
| 底色 | 背景色（念错=红、漏读=删除线、多读=斜体灰） | `errorType` ＋ `accuracy` |
| 次级 | 下划线粗细，三档 | `monotone` 的 0–1 强度 |
| 第三层 | 右上角标（`‖` 不该停 / `·` 该停） | `breakError` |

「三样都占」那一格是这份快照存在的主要理由：**三层同时出现**。
参考实现的查表结构（一个词只能显示一种错误）画不出那一格。
详见 `docs/decisions.md` 0045。
